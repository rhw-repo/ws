#### To run these projects

1. This repo contains multiple separate projects
   (therefore root doesn't run anything itself).

Clone the repository:

```
git clone https://github.com/rhw-repo/testing
```

Navigate to the project directory you want to run:

```
cd <directory name>
```

2. Install dependencies and run locally:

```
npm install
npm run watch
```
