### Webpack

[The Odin Project: Webpack](https://www.theodinproject.com/lessons/javascript-webpack#webpack)

Introduction to webpack explaining

- bundling
- src and dist
- bundling JavaScript
- Handling HTML
- Loading CSS
- Loading images
- Webpack dev server
- Using a source map

To run this project:

```
cd odin-webpack
```

Run:

```
pnpm webpack serve
```

Open browser tab: localhost:8080
