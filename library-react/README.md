# MERN Stack App

## Overview

This app was created as a demonstration of a full stack app specifcally for the [Chingu](https://www.chingu.io/) staff team.
Demonstrates the client communicates with a server capable of handling data to be persisted by the database.

Visit the app here: [Live demo](https://client-production-f0d0.up.railway.app/login)

### Dev Dependencies

Frontend:

- [React](https://react.dev/), JavaScript, [Tailwind CSS](https://tailwindcss.com/), in [Vite](https://vite.dev/guide/)
- [TanStack Query](https://tanstack.com/query/latest/docs/framework/react/overview)
- [DOMPurify](https://github.com/cure53/dompurify)
- [React Router](https://reactrouter.com/home)
- [dotenv](https://github.com/motdotla/dotenv)

Server side:

- [Node.js](https://nodejs.org/en)
- [Express.js](https://expressjs.com/)
- [Express-Sessions](https://expressjs.com/en/resources/middleware/session/)
- [Express-Validator](https://express-validator.github.io/docs/)
- [MongoDB](https://www.mongodb.com/products/platform) with data modelling using [Mongoose](https://mongoosejs.com/)
- [bcrypt](https://github.com/kelektiv/node.bcrypt.js)
- [Helmet](https://helmet.js.org/)

Tooling:

- [pnpm](https://pnpm.io/)
- [npm](https://www.npmjs.com/)
- [Prettier](https://prettier.io/)
- [ESLint](https://eslint.org/)

### Features

This project includes:

- Sign-up & log in
- Page to create a tagged list of books and deleted any book if required.
- Book list stored in the database, allowing users to revisit their list each time they log in.
